# TP - Typage avancé Typescript

TPs associés au module **5.1 - Typage avancé** (Conditional Types, `infer`, Recursive Types, Template Literal Types).

## Prérequis

```bash
npm ci
```

## Structure des branches

Chaque partie du TP dispose de 2 branches :

| Branche | Contenu |
|---|---|
| `tp5.1-p1` | **Partie 1** — Point de départ : typer des clefs d'i18n |
| `tp5.1-p1-solution` | Solution de la Partie 1 |
| `tp5.1-p2` | **Partie 2** — Point de départ : typer des routes paramétrables |
| `tp5.1-p2-solution` | Solution de la Partie 2 |

## Lancement

```bash
npm start        # vite dev sur http://localhost:5173
npm run typecheck
```

Ces TPs se jouent avant tout **dans l'IDE** — l'objectif est de valider les types (hover, autocomplétion, erreurs de compilation), pas de faire tourner beaucoup de code.
